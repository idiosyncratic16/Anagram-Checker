# 🔤 Anagram Checker

A simple Java program to check whether two given strings are **anagrams** of each other.

## 👨‍💻 Author

**Vedant Pathak**

## 📌 About the Project

An anagram is a word or phrase formed by rearranging the letters of another word or phrase.

For example:

* `listen` → `silent` ✅
* `triangle` → `integral` ✅
* `hello` → `world` ❌

This program removes spaces, converts the strings to lowercase, sorts their characters, and compares the resulting character arrays.

## 🛠️ Technologies Used

* Java
* Arrays
* Strings
* Sorting
* Scanner

## 🚀 How to Run

1. Make sure Java is installed on your system.
2. Clone this repository.
3. Compile the program:

```bash
javac AnagramChecker.java
```

4. Run the program:

```bash
java AnagramChecker
```

5. Enter two strings when prompted.

## 💻 Example

```text
Enter first string: listen
Enter second string: silent

The strings are Anagrams.
```

## ⏱️ Complexity

**Time Complexity:** `O(n log n)`

**Space Complexity:** `O(n)`
